AI QUOTEX PRO V2.2 - Binance Spot & Futures

INSTALL / UPDATE:
1. Extract this ZIP into a NEW folder. Keep your old app folder as backup.
2. Open the extracted folder.
3. Click the Windows File Explorer address bar, type cmd, press Enter.
4. Run: python -m pip install -r requirements.txt
5. Run: python -m streamlit run app.py

Inside the app, use the Dashboard selector in the left sidebar:
- Forex / OTC: existing Forex and OTC screenshot review features.
- Binance Spot & Futures: public Binance market data analyzer.

Binance features:
- Spot and USD-M Futures public candle data
- BTC, ETH, BNB, SOL, XRP, ADA, DOGE, TRX, LINK, AVAX pairs
- 15m / 1h / 4h trend confirmation, EMA, RSI, MACD, Bollinger Bands, ATR and volume
- Rule-based BUY / SELL / WAIT or LONG / SHORT / WAIT
- Illustrative ATR reference levels, futures funding and open interest when available
- Signal history and CSV export

IMPORTANT:
- No Binance API key is required; only public market data is read.
- No orders are placed. No exchange account is connected.
- Spot SELL is not a short sale.
- Futures are high risk. This is a research tool, not financial advice.
- Scores measure rule confluence, not probability of profit. No signal is guaranteed.
- Funding and open-interest endpoints may be unavailable in some regions/networks.
